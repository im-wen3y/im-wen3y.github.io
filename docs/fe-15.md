# FE-15 홈 구현

- 공개 글을 최신순으로 조회해 최근 글을 표시합니다. draft는 제외합니다.
- 글이 5편보다 적으면 실제 편수만 표시합니다.
- 공개 글이 없으면 “아직 공개된 글이 없습니다.”를 표시하고 주제 영역을 숨깁니다.
- 글 카드는 `/blog/{id}`, 주제 칩은 `/tags/{slug}`, 전체 글 링크는 `/blog`로 이동합니다.
- 도착 페이지 구현은 FE-16·17·24에서 진행합니다. FE-15만으로 전체 이동 경로가 완성되지는 않습니다.

## 확인한 결정과 남은 항목

홈 구성에 대한 답변을 docs/spec.md의 결정 사항에도 반영했습니다.

- I-04: 공개 글의 태그에서 자동 생성합니다. [제안] 표시 순서는 FE-06 집계 순서(글 수 내림차순)를 따릅니다.
- I-06: 최근 글은 최대 5편을 표시합니다.
- I-07: Hero의 “글 둘러보기”, 최근 글 제목 옆 “전체 보기”, 하단 “모든 글 보기”를 모두 유지합니다.
- I-05: 기존 홈 시안의 “주제 · 날짜” 순서를 유지하며 목록과의 통일 여부는 결정하지 않았습니다.

`HomeContent.astro`는 입력 데이터와 표시 편수를 받아 그립니다. 운영 데이터 조회는 `index.astro`에서 처리합니다.
